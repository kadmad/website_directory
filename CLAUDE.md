# Project Overview

A Django-based website directory that catalogs top websites with SEO metrics and screenshots. Users can browse, add, and comment on website entries. The app auto-captures screenshots via Selenium and scrapes SEO data (Domain Authority, Moz Rank, SEMrush Rank, website worth) from sitelike.org.

## Tech Stack

| Layer | Library | Version |
|---|---|---|
| Web framework | Django | 4.2.6 |
| Database | PostgreSQL (psycopg2-binary) | 2.9.9 |
| Forms | django-crispy-forms | 2.0 (bootstrap4 pack) |
| HTML parsing | BeautifulSoup4 | 4.12.2 |
| Screenshot capture | Selenium + Chrome | 4.13.0 |
| Image processing | Pillow | 10.0.1 |
| HTTP client | requests | 2.31.0 |

No React/frontend build toolchain — templates are server-rendered Django HTML with Bootstrap 4.

## Dev Commands

All Django commands run from the `sitelike/` directory:

```bash
cd sitelike

# Install dependencies
pip install -r ../requirements.txt

# Database setup (requires PostgreSQL running locally)
python manage.py migrate            # Apply all migrations
python manage.py createsuperuser    # Create admin user

# Development server
python manage.py runserver          # http://127.0.0.1:8000

# Migrations
python manage.py makemigrations     # Generate new migration files
python manage.py migrate            # Apply pending migrations

# Tests
python manage.py test directory                                       # Run all app tests
python manage.py test directory.tests.SpecificTestCase               # Run a single test class

# Utility scripts
python script.py                    # Scrape + import 100 top websites
python sitemap_generator.py         # Regenerate sitemap.xml
```

## Architecture Notes

**URL structure**: Root `/` redirects to `/websites/`. All website routes live under `/websites/`. URLs defined in `sitelike/urls.py`.

**View pattern**: Standard Django CBVs — `ListView`, `DetailView` (custom `View` subclass for POST support), `CreateView`, `UpdateView`, `DeleteView`. No DRF/API layer.

**Screenshot pipeline**: `DirectoryCreateView` calls `capture_website_screenshot(url)` in `utils.py`. Selenium opens Chrome (non-headless, maximized), takes a PNG screenshot, resizes to 450×450 with Pillow, saves as WebP to `media/snaps/<domain>_thumbnail.webp`, deletes the intermediate PNG.

**Bulk import**: `script.py` GETs sitelike.org, parses the page with BeautifulSoup to extract top 100 domains + SEO metrics, runs the screenshot pipeline for each, and bulk-inserts `Directory` records.

**Comments**: `Comment` model has FK to `Directory`. `DirectoryDetailView` handles both GET (render form) and POST (validate + save comment) on the same URL.

**Template rendering**: Crispy Forms with `CRISPY_TEMPLATE_PACK = 'bootstrap4'`. Grid uses `col-md-2` ad sidebars + `col-md-8/9` content area.

**Media files**: Served by Django in DEBUG mode via `static()` URL helper. `MEDIA_ROOT` is `sitelike/media/`.

## Conventions

- **Models**: Extend `TimestampedModel` from `base_models.py` to get `created_at` / `updated_at` fields.
- **Forms**: Use `ModelForm` with explicit `fields` list. Crispy Forms for rendering.
- **Views**: Class-based views preferred. `success_url` uses `reverse_lazy`.
- **URL names**: kebab-case — `website-list`, `website-detail`, `website-create`, `website-update`, `website-delete`.
- **Templates**: Live at `directory/templates/directory/<name>.html`. Follow naming: `directory_list.html`, `directory_detail.html`, `directory_form.html`, `directory_confirm_delete.html`.
- **Categories**: Fixed 20-choice tuple in `Directory.CATEGORY_CHOICES`. Add new categories by extending the list **and** creating a migration.
- **Images**: Always WebP format, stored under `media/snaps/`, referenced via `image_url` CharField (relative path string, not a FileField).

## Important Rules

- **NEVER change the DB schema without creating a migration.** Always run `python manage.py makemigrations` after any model change, then `python manage.py migrate`.
- **NEVER hardcode secrets or new credentials in settings.py** — the existing hardcoded DB password is a known tech debt; do not add more.
- **NEVER delete migration files.** If a migration needs to be reversed, use `migrate <app> <previous_migration>`.
- **NEVER run `manage.py` commands from the repo root** — they must be run from `sitelike/`.
- **Do not add new INSTALLED_APPS** without verifying they are in `requirements.txt`.
- **Do not bypass CSRF** — all POST forms must include `{% csrf_token %}`.
- **Do not store screenshots outside `media/snaps/`** — the `MEDIA_ROOT` and URL routing depend on this path.
- **Do not use `DEBUG=True` in production** — settings are currently development-only.
